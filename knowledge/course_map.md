# Course map

01:09), and splits each big trading topic into parts (Day 14, 00:55). Status: **learned**,
**partial** (some parts of a multi-part topic still missing), **not received**.

Trading topics are taught in this order (Day 12, 00:42): liquidity → fair value gaps →
order blocks → equilibrium, then execution, daily bias, risk, and backtesting.
